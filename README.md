## 📖 Project Overview

The `KMeans_Clustering_Algorithm.ipynb` notebook includes:

* **Loading and exploring** the bank marketing dataset
* Performing **Exploratory Data Analysis (EDA)** with visualizations to understand key features
* Preprocessing the dataset (handling categorical & numerical data)
* Applying the **K-Means Clustering** algorithm to segment customers
* Using the **Elbow Method** and **Silhouette Score** to determine the optimal number of clusters
* Visualizing customer clusters to interpret the results

This project showcases the use of **unsupervised learning** to derive meaningful insights from unlabelled data!

---

## 🗂️ Dataset

* **Source:** Bank Marketing Dataset (often used for customer segmentation tasks)
* **File Used:** `bank-full.csv`
* **Key Columns:**

  * Age, Job, Marital status, Education
  * Balance, Loan status, Contact method
  * Duration of last contact, Previous campaign outcome

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/kmeans-customer-segmentation.git
   cd kmeans-customer-segmentation
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Launch the notebook:

   ```bash
   jupyter notebook KMeans_Clustering_Algorithm.ipynb
   ```

4. Run all cells to reproduce the clustering analysis and visualizations! 🚀
